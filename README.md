# Sistema Web de Gestión Académica Universitaria

## Descripción
Plataforma web que centraliza y automatiza la administración académica universitaria, facilitando la gestión de estudiantes, docentes, matrículas, calificaciones, asistencia y reportes. Busca reducir el manejo manual de datos, aumentar la trazabilidad de la información y ofrecer acceso diferenciado según el rol del usuario (administrador, docente o estudiante).

## Objetivo
Consolidar y mejorar la administración académica universitaria mediante una plataforma en línea que facilite la gestión de estudiantes, docentes, matrículas, notas, asistencia y reportes, disminuyendo el manejo manual de datos y aumentando la trazabilidad de la información.

## Funcionalidades principales
- Registro y administración de estudiantes y docentes.
- Gestión del proceso de matrícula por semestre académico.
- Registro y modificación de calificaciones por asignatura.
- Control de asistencia estudiantil por fecha y asignatura.
- Generación de informes académicos filtrables por período y asignatura.
- Autenticación de usuarios y control de accesos basado en roles.

## Alcance
El sistema cubre el registro y gestión de estudiantes y docentes, administración de matrículas, inscripción y consulta de calificaciones, seguimiento de asistencia y elaboración de informes académicos, incluyendo autenticación y control de accesos por rol.

**No incluido en esta fase:** aplicación móvil nativa, integración con sistemas externos, pagos en línea, ni despliegue productivo.

## Usuarios del sistema
| Usuario | Función |
|---|---|
| Administrador | Supervisa usuarios, materias, matrículas y genera informes. |
| Docente | Registra calificaciones, lleva el control de asistencia y revisa datos de sus clases. |
| Estudiante | Accede a sus notas, horario, asistencia e información académica. |

## Herramientas utilizadas
- **Frontend:** HTML, CSS, JavaScript, Bootstrap.
- **Backend:** PHP o Python.
- **Base de datos:** MySQL.
- **Modelado:** Draw.io / StarUML.
- **Gestión de proyecto:** Trello y GitHub.
